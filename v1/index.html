    Deployment, privacy, and safe defaults

    Local file mode: feature search, fusion rules, prompt generation, JSON export and import need no host. Browser-managed storage under file:// varies between browsers. PWA installation and service-worker caching require HTTPS or localhost.

    Networking: WebRTC needs discovery/signaling; authoritative play needs a server. Offline mode cannot provide live multiplayer, cloud saves or leaderboards. Do not embed API secrets in public client code.

    Security: user-generated scripts should run only in properly sandboxed contexts; assume all multiplayer clients are untrusted. Use opt-in analytics, protect chat, never expose exact location without consent and provide safe reporting mechanisms.

    Zero-Harm / Anti-Inversion: progress should represent meaningful player benefit rather than manipulative retention. No loot boxes, surveillance-by-default or hidden behavioural profiling.
